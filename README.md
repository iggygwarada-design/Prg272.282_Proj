# Baobab Ridge Wildlife Rehabilitation Records System

**Project PRG2782 | Programming 2782**

This repository contains a C# Windows Forms application built for a fictional wildlife centre to manage animals in their care. It was developed using .NET 8.0.

The desktop application allows users to:

* Add, view, update, and delete animal records.
* Automatically calculate an animal's recovery status and housing unit based on a veterinary Recovery Score.
* Generate and save a summary report of all animals currently in the system.

Data is stored locally using plain text files without the use of external databases.
